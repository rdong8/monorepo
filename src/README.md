# Demos

This directory contains several demo projects that illustrate how to use some of the trickier features of C++/Bazel.

## Benchmarks

Benchmarks with Google Benchmark.

## library_usage

Simple demo of usage of some common C++ libraries in Bazel.

## toy

The [LLVM MLIR toy language compiler](https://mlir.llvm.org/docs/Tutorials/Toy/).

## tmp

Scratchpad.
